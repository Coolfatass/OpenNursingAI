# MVP 范围

## 当前目标

首个 MVP 是基于模拟数据的护理交班智能助手，用于验证信息结构化和 SBAR 草稿生成是否能减少重复整理工作。当前仓库尚未包含可运行 MVP。

## 当前输入

现阶段由护理人员手动输入模拟护理交班信息，包括基本情况、主要诊断、意识、生命体征、呼吸、饮食营养、排泄、活动、皮肤、管路、用药治疗、异常检查、已完成事项和待完成事项。

未来如需接入医院后台数据，必须先完成合法授权、数据安全评估、机构批准、接口验证和临床测试；不属于当前 MVP。

## 当前输出

系统规划生成可编辑的 SBAR 草稿：Situation、Background、Assessment、Recommendation，并标记信息缺失、潜在高风险内容和需要人工确认的字段。

## 责任与审核

护理人员负责审核 AI 输出并承担最终专业判断责任。任何输出都不能自动用于诊断、处方、医嘱、治疗调整、临床报警或护理任务执行。

## 不在当前范围内

不接入真实 HIS/EMR，不诊断，不开具医嘱，不自动改变治疗方案，不自动发送临床警报，不自动执行护理任务，不保存真实患者资料。
