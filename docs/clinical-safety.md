# 临床安全边界

## 长期功能风险分级

- 低风险：文本格式整理、基于医院审定知识库的健康教育草稿、模拟案例和非临床任务提醒；
- 中风险：交班摘要、护理文书草稿、护理业务查房材料、护理质量管理辅助和护理计划建议；
- 高风险：风险预测、生命体征预警、异常报警、用药安全建议、病情恶化判断、管路或设备自动控制、处置建议和自动执行护理任务。

风险等级只表示需要的审查强度，不代表功能已经获准开发或临床使用。

## 当前阶段

首版只做低风险及受严格人工审核约束的中低风险功能，不开发高风险自动临床决策。当前 MVP 仅规划使用护理人员手动输入的模拟数据。

后续任何医院后台数据接入，都必须先完成合法授权、数据安全评估、机构批准、接口验证、临床测试和上线监测。

## 输出要求

所有 AI 输出必须标注“AI 生成内容”，显示人工审核提示、生成时间、模块版本、信息缺失提示和可能错误提示，并允许人工编辑和追溯。

护理人员及经过授权的护理管理人员可以参与审核；最终专业判断由当班护理人员承担。涉及临床输出的 PR 至少需要技术审核和护理专业审核；高风险功能还需要安全、伦理、法律或医疗专家审核。
