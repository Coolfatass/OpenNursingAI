# 项目概览

OpenNursingAI 的使命是让护理人员把更多时间用于观察病情、沟通和专业护理，而不是重复的信息整理工作。

## 长期服务范围

项目长期面向全球及中国医院的护理场景，计划分阶段探索：

1. 以医院审定护理健康教育知识库为依据的宣教内容生成；
2. 护理文书智能生成；
3. 智能护理交接班；
4. 护理任务提醒；
5. 护理业务查房和疑难病例讨论材料生成；
6. 护理风险评估辅助；
7. 生命体征预警支持；
8. 用药安全辅助；
9. 管路及设备管理辅助；
10. 护理质量管理支持。

这些内容属于长期产品版图。每个模块都必须单独完成需求分析、风险分级、数据授权、临床审核、技术验证和机构批准，不能因为属于同一项目就直接视为可用。

## 当前阶段

当前仓库是 Documentation Baseline，仅进行需求研究、治理建设和模拟数据规划。首个 MVP 选择护理交班助手，目标是将人工输入的模拟护理信息整理为可编辑、可追溯的 SBAR 草稿。护理人员或后续经批准的医院后台数据可以作为输入来源，但当前版本不接入医院系统。

项目采用开放协作方式，连接护理人员、医生、研究者、AI 工程师、软件工程师、医疗信息化人员、安全、伦理和法律人员。
