# OpenNursingAI

OpenNursingAI（开放护理人工智能协作计划）致力于通过安全、可审核、以人为中心的人工智能工具，减少护理人员的重复性工作。

> **文档基线：当前没有可运行 MVP，不用于临床决策。** 仓库目前只包含项目治理、研究规划和协作文档。未来的首个 MVP 将以模拟数据为基础，探索护理交班 SBAR 草稿生成；所有输出必须由护理专业人员人工审核。
