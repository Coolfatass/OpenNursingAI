# OpenNursingAI

OpenNursingAI（开放护理人工智能协作计划）致力于通过安全、可审核、以人为本的人工智能工具，减少护理人员的重复性工作。

> **文档基线：当前没有可运行 MVP，不用于临床决策。** 仓库目前只包含项目治理、研究规划和协作文档。未来的首个 MVP 将以模拟数据为基础，探索护理交班 SBAR 草稿生成；所有输出必须由护理专业人员人工审核。

## 长期产品愿景

项目长期面向全球及中国医院护理场景，计划分阶段探索：

- 以医院审定知识库为依据的智能护理健康教育生成；
- 护理文书智能生成；
- 智能护理交接班；
- 护理任务智能提醒；
- 护理业务查房和疑难病例讨论材料生成；
- 护理风险评估辅助；
- 生命体征预警支持；
- 用药安全辅助；
- 管路及设备管理辅助；
- 护理质量管理支持。

上述内容是长期产品愿景，不代表当前已经实现，也不代表已具备临床应用条件。首个 MVP 仍限定为基于模拟数据的护理交班助手。
